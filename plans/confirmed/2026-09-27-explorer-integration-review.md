## A. 主线澄清（规格起草前）

### A1 — v1 右键能力面

**确认**：选 B — 打标 / 去标 / 看标签 + 按标签查找；无关系 CRUD、无 expand；**多选批量打标为一等场景**。

### A2 — 多选时各动作

**确认**：选 B — 打标/去标对全部选中生效；看标签仅单选；查找与选中无关。

### A3 — 交互 UI 挂载

**确认**：选 A — 进程外助手 `ExplorerHost`（后定 WPF）；稀疏包 `IExplorerCommand` 只负责拉起。

### A4 — 按标签查找落地

**确认**：选 A — Host 内 preview；点选后 `file` → Explorer `/select`，`folder` → 打开目录；默认不 expand。

### A5 — 路径 / kind / 存在性

**确认**：选 A — 与 CLI §3–4 同规则；不传 `displayName`；勾选才 `createMissing`。

### A6 — 合法壳对象

**确认**：选 A — 仅真实 FS 文件/文件夹（含 UNC）；不解析 `.lnk` 到目标；拒虚拟命名空间。

### A7 — 批量数量上限

**确认**：选 B — 最多 **100** 项。

### A8 — 菜单形态 + 空白处

**确认**：选 A — 子菜单 EverythingLabeled；空白处仅「按标签查找」。

### A9 — `confirmUntag`

**确认**：选 A — 读 AppData，缺省 true；Host 不写回 config。

### A10 — 实现方案

**确认**：统一方案 1 — 稀疏包 `IExplorerCommand` + 进程外 Host；Host UI = **WPF**。

### A11 — 设计分节确认

**确认**：§1 组件、§2 菜单/路径/API、§3 Host UI/配置/非目标 — 均 ok 后落盘初稿。

## B. Grill 审核（落盘修订）

### Q1 — 合法选中 / 100 上限由谁拦

**确认**：选推荐 A。

- DLL 只尽量启停菜单；**硬规则在 Host**

### Q2 — 打开时 health/meta

**确认**：选推荐 A。

- **每次**打开 Host 必做 health；有 token 再 meta；失败置顶阻断

### Q3 — `baseUrl` 是否仅 `127.0.0.1`

**确认**：选推荐 A。

- 与扩展一致：仅 `http://127.0.0.1`；拒绝 `localhost` / `::1`

### Q4 — 批量 API 错误是否继续

**确认**：选推荐 A。

- **401 / 缺配置整批中止**；其余按项继续并汇总

### Q5 — 打标别名输入形态

**确认**：选推荐 A。

- 与扩展一致：**每次提交一个别名**

### Q6 — `--paths-file` 安全

**确认**：选推荐 A。

- 私有 tmp 目录 + 用户 ACL；读完即删；残留超时清理

### Q7 — 选中 >100 时菜单

**确认**：选推荐 A。

- DLL **不**因数量灰掉打标/去标；Host 阻断；**不**静默截断

### Q8 — 混选丢弃非法项

**确认**：选推荐 A。

- 提示「已忽略 N 个不支持的项」

### Q9 — 去标是否每次一个别名

**确认**：选推荐 A。

- 与打标对称；单选列表点删 = 一次一个别名

### Q10 — find 是否翻页 `query`

**确认**：选推荐 A。

- v1 **仅** preview；无「加载更多」

### Q11 — 打标/去标成功后窗口

**确认**：选推荐 A。

- **保持打开**，显示汇总

### Q12 — junction / 挂载点

**确认**：选推荐 A。

- 与 CLI 符号链接规则同一套（规格点名含 junction）

### Q13 — 批量取消

**确认**：选推荐 A。

- 可取消未发出请求；已发出不撤销；汇总含「已取消未发送」

### Q14 — 与 CLI 路径逻辑关系

**确认**：选推荐 A。

- **强制**共享 PathUri 库，禁止分叉实现

### Q15 — 打标存在性检查时机

**确认**：选推荐 A。

- 打开 tag 面板时预检并默认排除无效项；提交前复核

### Q16 — find 打开命中后窗口

**确认**：选推荐 A。

- **保持打开**

### Q17 — 重复路径

**确认**：选推荐 A。

- 按规范化 `file://` **去重**

### Q18 — Invoke 与 Host

**确认**：选推荐 A。

- **即发即忘**，不等待 Host 退出

### Q19 — UI 文案语言

**确认**：选推荐 A。

- 菜单项与 Host UI **简体中文**；子菜单可用产品名

### Q20 — 批量并发度

**确认**：选 **C**（非初荐 A），并约定缺省。

- config 可选 `maxConcurrency`；**缺省键或未配置 = 4**
