## A. 主线澄清

### Q1 — 常驻形态

**问题**：全局快捷键打开 Find 需要常驻进程。选哪种形态？

| 选项 | 含义 |
|---|---|
| **A（推荐）** | 单独小托盘/后台进程：注册全局热键 → 唤起 `Host --mode find`；可开机自启 |
| **B** | Host 自己常驻（关窗进托盘），热键只唤起已有实例 |
| **C** | 不自建常驻：只提供 `.lnk` / 脚本，用户用系统或 PowerToys 自绑快捷键 |

**确认**：选推荐 **A**。

### Q2 — 快捷键可配置程度

**问题**：快捷键要「多自定义」？

| 选项 | 含义 |
|---|---|
| **A（推荐）** | 默认 `Alt+L`，可在 AppData 配置文件里改；本阶段不做设置 UI |
| **B** | 写死 `Alt+L`，暂不可改 |
| **C** | 托盘菜单/小窗里可改快捷键并写回配置 |

**确认**：选推荐 **A**。

### Q3 — 开机自启

**问题**：是否做开机自启？

| 选项 | 含义 |
|---|---|
| **A（推荐）** | 可选：配置项默认开；托盘菜单「开机自启」勾选可关 |
| **B** | 本阶段不做自启；用户自己放快捷方式或任务计划 |
| **C** | 强制自启，无可关入口 |

**确认**：选推荐 **A**。

### Q4 — Find 已打开时热键行为

**问题**：热键按下时，若 Find 窗口已打开？

| 选项 | 含义 |
|---|---|
| **A（推荐）** | 只对 Find 单实例：已有则前置/激活；没有则新起 Host find。打标/去标/看标签仍可多开 |
| **B** | 每次热键都新开一个 Find |
| **C** | 全局 Host 强制单实例（任意模式互斥） |

**确认**：选推荐 **A**。

### Q5 — 托盘进程落仓库位置

**问题**：托盘进程怎么落仓库？

| 选项 | 含义 |
|---|---|
| **A（推荐）** | 新项目（如 `EverythingLabeled.Tray`）：只负责热键 + 自启 + 唤起/激活 Find |
| **B** | 给 Host 加 `--mode tray`：无窗常驻 |
| **C** | 塞进 Service 守护进程 |

**确认**：选推荐 **A**。

### Q6 — 配置存放

**问题**：热键/自启配置放哪？

| 选项 | 含义 |
|---|---|
| **A（推荐）** | 沿用现有 Explorer/CLI AppData `config.json`，增字段 |
| **B** | Tray 单独一份 config |
| **C** | 只放环境变量 / 命令行，不写文件 |

**确认**：选推荐 **A**。

### Q7 — 热键注册失败

**问题**：热键被占用或注册失败时？

| 选项 | 含义 |
|---|---|
| **A（推荐）** | 托盘气泡提示一次；Tray 继续跑；热键暂失效直至改配置并重启 Tray |
| **B** | 静默失败，无提示 |
| **C** | 自动尝试后备键并提示已改用何键 |

**确认**：选推荐 **A**。

## B. 实现路线

### Q8 — Find 激活机制

**问题**：在已定产品决策下，Find 如何被激活？

| 选项 | 含义 |
|---|---|
| **1（推荐）** | Tray：`RegisterHotKey` + NotifyIcon；Find 用命名 Mutex + 命名管道 Activate |
| **2** | Tray 只 `Process.Start`；靠窗口标题枚举前置 |
| **3** | Tray 内嵌 Find UI |

**确认**：选推荐 **1**。

## D. Grill Round 1 — 部署 / 入口 / 竞态

### Q1 — Tray 如何定位 Host.exe

**问题**：Command 只认与 DLL 同目录的 Host。Tray 的「同目录」如何钉死？

| 选项 | 含义 |
|---|---|
| **A（推荐）** | 只认 Tray.exe 同目录的 Host；部署要求同目录拷贝 |
| **B** | config 增加可选 `hostPath` |
| **C** | 先同目录，再回退稀疏包目录等启发式 |

**确认**：选推荐 **A**。

### Q2 — 右键 Find 是否也强制单实例

**问题**：第二次右键「按标签查找」是否也 Activate 后退出？

| 选项 | 含义 |
|---|---|
| **A（推荐）** | 所有 Find 入口统一单实例（热键 / 托盘 / 右键 / CLI） |
| **B** | 仅 Tray 热键/菜单单实例；右键/CLI 仍可多开 |

**确认**：选推荐 **A**。

### Q3 — 无安装器时 Tray 第一次怎么起来

**问题**：`runAtStartup` 默认 true 在 Tray 未跑过时不会写 Run。首次如何启动？

| 选项 | 含义 |
|---|---|
| **A（推荐）** | 文档/脚本要求手动启动一次；启动时若 `runAtStartup==true` 则写 HKCU Run |
| **B** | Service 启动时顺带拉 Tray |
| **C** | 稀疏包 Register 流程附带启动/登记 Tray |

**确认**：选推荐 **A**。

### Q4 — 后台进程前置窗口常失败

**问题**：`SetForegroundWindow` 从 Tray/秒退第二 Host 常被拦。验收标准？

| 选项 | 含义 |
|---|---|
| **A（推荐）** | 尽力前置；失败则任务栏闪烁，不视为 P0 |
| **B** | 热键始终新开 Find，放弃单实例前置 |
| **C** | UI Access / 特殊完整性 |

**确认**：选推荐 **A**。

### Q5 — runAtStartup 写回与 Service 抢写 config

**问题**：两端都可能写 `config.json`，如何避免丢字段？

| 选项 | 含义 |
|---|---|
| **A（推荐）** | 读-改-写保留未知键；Tray 短重试；接受极罕见竞态 |
| **B** | 自启以注册表为准，菜单切换不写 config |
| **C** | 文件锁或独立 `tray.json` |

**确认**：选推荐 **A**。
