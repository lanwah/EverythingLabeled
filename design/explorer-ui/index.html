Explorer 右键界面 · 视觉稿

对齐「按标签查找」深色风格，重做打标 / 去标 / 看标签，并保留查找页。 每张卡片可进空状态或填充态，方便对照间距与层次。

按标签查找

芯片标签、预览列表（名称后展示该资源标签胶囊）、清空与打开；多标签 AND/OR 由 config 配置。已有 Host 深色参考的基线稿。

填充态 空状态

打标

路径列表、当前标签（点叉号去除）、别名输入、联想、创建缺失标签。底部无取消 / 打标按钮，Enter 提交。

填充态 空状态

去标

路径与当前标签。点叉号去除；标签多时可检索后再去。无别名，底部无取消 / 去标。

填充态 空状态

看标签

单路径展示、标签列表、切换到打标 / 去标。

填充态 空状态

管理资源

右键子菜单。按标签查找后删除选中资源，或填入新地址打上同样的标签并删除原资源。查找页仍只打开。

列表 删除确认 替换 空状态

管理标签

右键子菜单第五项。搜索词库、改名、删除确认。不使用选中路径，芯片 × 仍是去标。

列表 改名 删除确认 空状态

浏览器扩展 · 打标 / 查找

Popup 顶部 switch +「打标模式 / 查找模式」（默认打标）。打标：当前网页与标签芯片（× 去标）、别名 Enter。查找：芯片查询 + 更高结果区（按标签查询预览条数占位，名称后标签胶囊）、双击打开；拼首联想条数见设置；类型过滤见设置（默认仅链接）。窗高仍 600px。

浏览器扩展 · 管理标签

浏览器扩展 · 设置

服务地址、Token、去标确认、标签查询预览条数、拼首联想预览条数与预览资源类型（仅链接 / 全部，默认仅链接）。探测连接与保存。
