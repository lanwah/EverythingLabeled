交互说明（图中体现不全时以本文为准）

  1. 打标：无「打标」按钮。别名框按 Enter 提交打标（有联想时采用当前高亮项，与现有 suggest 行为一致）。
  2. 去标：无「去标」按钮。点击「当前标签」芯片上的 × 去除该标签。
  3. 预览空提示间隙：芯片输入框与「添加标签后，这里显示匹配结果」之间保留可见垂直间隙（约 12px）。
  4. 预览资源类型：可配置「仅链接」或「全部（文件 / 文件夹 / 链接）」；默认「仅链接」。配置项在设置页，键 previewResourceType（links / all）。本填充态按默认仅链接示意。
  5. 拼首联想浮动（与结果区不同）：输入末词时浮动叠在输入框下；高度 = 下方可用空间（铺满预留命中区），不按预览条数限行。Chrome Popup 无法画到窗外。
  6. 结果区占位（与联想不同）：匹配结果在芯片框下方文档流；高度只按 Options「预览条数」预留（不压缩）；条数不足仍占位。「预览 N 条」在区外紧跟。Popup 窗口贴合内容无滚动条（上限 600px）。
  7. 结果行：无勾选框；单击仅高亮选中；双击打开该链接（本设计稿为静态示意，无法演示双击）。名称后展示该资源标签胶囊，布局与样式对齐「按标签查找」（preview API tags）。
  8. 清空：无「清空标签」「打开所选」按钮。有芯片时，输入框右侧显示清除图标（对齐「按标签查找」），一点清空全部预览芯片。
