# #12 MCP stdio host Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付薄客户端 `EverythingLabeled.Mcp.exe`（stdio MCP host）与 `EverythingLabeled.Mcp.Tools`，七个 `el_*` 工具只走 Service HTTP + Bearer，返回规格 §6 信封。

**Architecture:** 闸门抽到 Client `ElRequestRules`；新增 `LoadBaseUrl`（health 不要求 token）。Tools 依赖 `ElMcpRuntime` + 可选 `IElApi`，确认策略只在 Tools。Host 用 SCL 先解析 flag，再以**空 args** 启动 Generic Host + 官方 SDK stdio；配置启动快照；缺配置仍进会话，由 tool 返回 `config_missing`。

**Tech Stack:** .NET 8；`ModelContextProtocol` **2.2.0**（Host）/ `ModelContextProtocol.Core` **2.2.0**（Tools，若属性不在 Core 则 Tools 改引主包）；`System.CommandLine` **2.0.12**；`System.Text.Json` 经 Client `ElJson`；xunit。不用 Serilog、不用 `IHttpClientFactory`、不引用 Service / ASP.NET / SQLite。

**Spec:** [plans/2026-09-27-mcp.md](./2026-09-27-mcp.md)。Client/CLI 基线：[plans/2026-10-06-cli-impl.md](./2026-10-06-cli-impl.md)。HTTP：[plans/2026-09-26-http-api.md](./2026-09-26-http-api.md)。审核：[confirmed/2026-10-06-mcp-impl-review.md](./confirmed/2026-10-06-mcp-impl-review.md)（Q1–Q15 均选推荐 A）。

## Global Constraints

- TFM `net8.0`；`<Nullable>enable</Nullable>`；`<TreatWarningsAsErrors>true</TreatWarningsAsErrors>`。
- 只走 HTTP + Bearer（`el_health` 除外，不带 `Authorization`）。`IElApi` **不得改签名**。
- 覆盖优先级（均不写回）：`--config` / `--base-url` / `--token` > `EL_CONFIG` / `EL_BASE_URL` / `EL_TOKEN` > config 文件。未知 JSON 键忽略。`confirmUntag` 缺省 `true`。
- `baseUrl` 规范与现 `ElConfigLoader` 相同（绝对 `http`/`https`，恰好一个尾 `/`）。非法 → 视为缺 url。
- HTTP 整请求超时 **30s**（`HttpClient.Timeout`）；超时/连不上 → `connection_failed`（已有 `HttpElApi`）。
- stdout：进入 MCP 会话后 **仅** SDK 协议帧。`--help`/`--version` 仅在未进会话时写 stdout。日志 Console → **stderr**，最低 **Warning**。
- 成功 tool 内容：紧凑 JSON `{"data":...,"message":null|string}`（`ElJson.Options`，`message` 无 notice 时为 JSON `null`，不得省略）。`isError: false`。
- 失败：`{"error":{"code":"...","message":"..."}}`，`isError: true`。HTTP 业务码透传 `ElError.Code`/`Message`。
- 本地码：`config_missing` / `path_not_found` / `confirmation_required` / `bad_request` / `connection_failed`。`confirmation_required` 常量在 `ElErrorCodes`。
- 工具对外名：`el_tag` / `el_untag` / `el_tags` / `el_query` / `el_preview` / `el_suggest` / `el_health`。schema 参数 **snake_case**。
- 默认：`create_missing=false`；`el_query` limit **50** offset **0**；`el_preview`/`el_suggest` 省略 limit 时传 **10**；`expand` 仅 `"child"`；未传 `expand` 却传了 `max_depth`/`expanded_tag_limit` → 本地 `bad_request`。
- `aliases`：`string[]`，trim 后 1–100，空元素 → `bad_request`；不去重、不改大小写。
- `el_tag`：`FileTarget` 存在性（http(s)→`url`）；`el_untag`/`el_tags` 不查本地存在。相对路径 = **进程 cwd**。
- `el_untag`：`confirmUntag && confirm!=true` → 不发请求，`confirmation_required`。永不 `createMissing`。
- `el_health`：只需 `HasBaseUrl`；不要求 token。
- 业务 tool：无 `IElApi` 或无非空 token → `config_missing`，不发请求。
- 配置 **启动快照**；不热读文件。无 `IHttpClientFactory`；一个 `HttpClient` 单例。
- Host 用 `.WithTools<ElTools>()`（Tools 在类库，禁止只扫 entry assembly 而漏掉工具）。
- 不做：HTTP MCP、Resources/Prompts、CRUD tools、`el_meta`、安装器、写 config、协议级 stdio 门禁测、Inspector。
- commit subject：仓库递增 `#序号`（`git log -1 --format=%s` +1），**不要** backlog `#12`；不用 conventional commits。PowerShell here-string 传 `-m`。

闸门消息（英文，规格参数名）：

- target 非法：`"Target is not a valid path or URI."`

`ParseTarget` / `ResolveKindForTag` 行为与现 `CommandSupport` 相同（http(s)→`url`，否则 `FileTarget.ResolveKindForTag`）。`ParseLimit(null, d)` → `d`；`ParseOffset(null)` → `0`。string 重载：`null` 当省略；非法十进制（`NumberStyles.None` + invariant）走对应 fail 消息。

`CallToolResult` / `TextContentBlock` 以 **2.2.0** 包内类型为准：文本块内容为 `ElJson.Options` 序列化的信封；`IsError` 按规格。若 SDK 属性名不同，测里用反射或公开属性读取 `IsError` 与第一块文本。

| 方法 | Name | Hints | 参数 |
|---|---|---|---|
| `Tag` | `el_tag` | （不标 ReadOnly） | `target`, `aliases` (`string[]`), `create_missing` 默认 `false` |
| `Untag` | `el_untag` | `Destructive=true` | `target`, `aliases`, `confirm` 默认 `false` |
| `Tags` | `el_tags` | `ReadOnly=true` | `target` |
| `Query` | `el_query` | `ReadOnly=true` | `q`, `expand?`, `max_depth?`, `expanded_tag_limit?`, `limit?`, `offset?` |
| `Preview` | `el_preview` | `ReadOnly=true` | 同 query 无 `offset` |
| `Suggest` | `el_suggest` | `ReadOnly=true` | `prefix`, `limit?` |
| `Health` | `el_health` | `ReadOnly=true` | （无业务参） |

`el_query` 的 Description **必须**包含：建议大结果集先 `el_preview`；默认 limit 仍为 50。

`el_untag` Description **必须**写清：`confirmUntag` 缺省 true 时需要 `confirm=true`，否则 `confirmation_required`；`confirmUntag==false` 时直接 remove。

业务 tool 顺序：闸门 → 若 `runtime.Api is null \|\| !runtime.HasToken` → Fail `config_missing` 同一配置句 → 调 `IElApi` → `Ok(data, message)` 或 `Fail(error)`。

`el_tag`：`ParseTarget` → `ResolveKindForTag`（fail 则原样，含 `path_not_found`）→ `ParseAliases` → `TagAsync`。

`el_untag`：闸门后查 token；再若 `runtime.ConfirmUntag && confirm != true` → Fail `ElErrorCodes.ConfirmationRequired`，message：`"Call el_untag again with confirm=true to remove the aliases."`；否则 `UntagAsync`。`confirm=true` 且 `ConfirmUntag==false` 仍直接 untag。

`el_health`：`!runtime.HasBaseUrl \|\| runtime.Api is null` → `config_missing`；否则 `HealthAsync`（不查 token）。

`el_query`：`ParseRequiredText(q, "q must not be empty.")`；`ParseExpand(expand, max_depth, expanded_tag_limit)`；`ParseLimit(limit, 50)`；`ParseOffset(offset)`；然后 `QueryAsync`。preview 默认 limit 10、不传 offset。suggest：`ParseRequiredText(prefix, "prefix must not be empty.")`；`ParseLimit(limit, 10)`；`SuggestAsync(prefix 原样，trim 后空已拦；非空 prefix 提交 **trim 后** 与 CLI `ParseRequiredText` 一致——CLI 对 q/prefix 是 trim 后提交；与规格「原样提交」冲突时 **跟现 CLI**：`ParseRequiredText` 已 trim。prefix 只空白 → 本地 `bad_request`）。

csproj：`net8.0`，引用 Client + PathUri（若 Client 已转引则不必直接引 PathUri），PackageReference `ModelContextProtocol.Core` 2.2.0。`InternalsVisibleTo` 仅当测试需要；优先 public。**禁止** ProjectReference Service、禁止 ASP.NET 包。

```csharp
namespace EverythingLabeled.Mcp;

public sealed class McpInvocation
{
    public required string[] Args { get; init; }
    public required TextWriter Stdout { get; init; }
    public required TextWriter Stderr { get; init; }

    public string DefaultConfigPath { get; init; } =
        Path.Combine(Environment.GetFolderPath(Environment.SpecialFolder.ApplicationData),
            "EverythingLabeled", "config.json");
    public IReadOnlyDictionary<string, string?>? Env { get; init; }
    public Func<ElMcpRuntime, CancellationToken, Task<int>>? RunHost { get; init; }
}

public static class McpApp
{
    public static Task<int> RunAsync(McpInvocation inv);
}
```

行为：

1. 若 args 含 `--version`（与 CLI 一样先于 SCL 组合限制）：stdout 一行含 `0.1.0`，stderr 空，exit 0。**不读 config**。
2. SCL root：options `--config` / `--base-url` / `--token`；标准 `--help`/`-h`。无子命令。help 英文。解析错误（未知 flag 等）：stderr 英文错误，stdout 不写 MCP 帧，exit **1**，不进 host。
3. `--help`：SCL help → stdout，exit 0，不读 config。
4. 否则组装 `ElConfigOverrides`，env 默认 `Environment.GetEnvironmentVariables()` 转字典（测试注入 `inv.Env`）。`Load` + `LoadBaseUrl`（可注入）。
5. 构造 `ElMcpRuntime`：
   - `Load` 成功：`HasBaseUrl=true`，`HasToken=true`，`ConfirmUntag=cfg.ConfirmUntag`，`Api` 由 host 侧创建（见 6）
   - `Load` 失败且 `LoadBaseUrl` 成功：`HasBaseUrl=true`，`HasToken=false`，`ConfirmUntag=base.ConfirmUntag`，token 用 `""` 建 `HttpElApi`
   - 两者失败：`HasBaseUrl=false`，`HasToken=false`，`ConfirmUntag=true`，`Api=null`
6. 若 `inv.RunHost != null`：调用它（测试用，**禁止**真 stdio）。否则 `Host.CreateApplicationBuilder(Array.Empty<string>())`（或等价空 args API）：
   - `Logging`：ClearProviders + AddConsole 且 `LogToStandardErrorThreshold = LogLevel.Warning`；`SetMinimumLevel(LogLevel.Warning)`
   - 若 `HasBaseUrl`：`AddSingleton<HttpClient>`（`BaseAddress=normalized`，`Timeout=30s`，`Accept: application/json`）+ `AddSingleton<IElApi>(sp => new HttpElApi(http, tokenOrEmpty))`
   - `AddSingleton(runtime with { Api = sp.GetService<IElApi>() })` —— 保证 Tools 拿到的 runtime.Api 与 DI 一致。实现时先建 runtime 骨架再在注册回调里填 Api，避免循环。
   - `AddMcpServer(options => { options.ServerInfo = new() { Name = "everything-labeled", Version = "0.1.0" }; }).WithStdioServerTransport().WithTools<ElTools>()`
   - `await host.RunAsync(ct)`
7. `Program.cs`：`return await McpApp.RunAsync(new McpInvocation { Args=args, Stdout=Console.Out, Stderr=Console.Error });`。**不要**把 stdout 设成 UTF-8 人类模式而干扰协议；不要往 stdout 写日志。
